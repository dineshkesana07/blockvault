Understanding Password Entropy & Key Formulation

GUIDE // SPEC-09
1. Shannon Entropy Formula
E = L × log&sub2(R)

Where L is secret length and R is the pool of possible glyphs. An incremental increase in secret length yields exponential improvements compared to merely adding rare symbols.

2. Length Outclasses Complexity

An 8-character password featuring symbols and mixed caps offers approx. ~52 bits. A 24-character password generated using standard alpha-numerics soars past >128 bits, rendering offline hash attacks mathematically impossible.
